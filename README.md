# Outback Sams

Numerical Grid Processor and Front-End Utility Interface.

## Overview
Outback Sams provides a structured 10-column front-end grid visualizer designed for numerical analysis and pattern processing. 

## Features
- **10-Column Grid Display:** Optimized layout for viewing numerical datasets and sequences.
- **Dynamic Input Generation:** Custom range rendering directly in the browser interface.
- **Responsive Layout:** Dark-mode UI built for desktop and mobile screen support.

## Tech Stack
- **Front-End:** HTML5, CSS3 (CSS Grid), JavaScript (Vanilla)
- **Deployment:** Netlify
- **Version Control:** GitHub
